## Proteção do ramo main
A regra de proteção do ramo `main` foi configurada para exigir a aprovação do check do Qodana antes de efetuar o merge de qualquer pull request, bloqueando alterações não conformes.

## Reflexão
O Qodana detetou corretamente o cheiro no código do projeto Battleship2, sinalizando métodos com elevada complexidade ciclomática e forçando a falha do quality gate no pull request. Os resultados demonstraram sensibilidade ao valor de `m_limit` configurado no perfil. Face à estratégia original descrita no livro *Object-Oriented Metrics in Practice*, a utilização do Qodana constitui uma aproximação simplificada, uma vez que utiliza limiares absolutos e fixos em vez de métricas estatísticas relativas ao sistema, e não suporta a validação simultânea de múltiplas condições lógicas combinadas.
